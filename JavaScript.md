# Введение в JavaScript

**JavaScript** — язык программирования, который изначально создавался для того, чтобы «оживлять» веб-страницы: делать их интерактивными.

Особенности JavaScript:

- Полностью интегрирован с HTML/CSS.
- Простые вещи делаются просто.
- Поддерживается всеми основными браузерами и включён по умолчанию.

JavaScript — это **язык браузера**, но сегодня он используется гораздо шире:

- на серверах (например, платформа **Node.js**);
- в мобильной разработке (React Native, NativeScript);
- на «умных» устройствах и в десктопных приложениях (Electron).

> Важно: в браузере у JavaScript есть ограничения (в целях безопасности), которых нет у серверного JavaScript. Например, обычный скрипт в браузере не может напрямую читать файлы на диске пользователя без его явного разрешения.

### Что такое движок JavaScript?

Движок (engine) — это программа, которая исполняет код JavaScript. Каждый браузер имеет свой движок:

- Chrome, Opera — **V8**;
- Firefox — **SpiderMonkey**;
- Safari — **JavaScriptCore (Nitro)**.

Принцип работы движка:
1. Движок (встроенный в браузер, если речь о браузере) читает («парсит») скрипт.
2. Затем преобразовывает («компилирует») скрипт в машинный код.
3. Машинный код запускается на выполнение.

### Что может JavaScript в браузере

- Добавлять HTML-разметку на страницу, изменять содержимое, менять стили.
- Реагировать на действия пользователя: клики мыши, движение курсора, нажатия клавиш.
- Посылать запросы на сервер без перезагрузки страницы (AJAX).
- Получать и устанавливать cookie, задавать вопросы посетителю, показывать сообщения.
- Запоминать данные на стороне клиента (`localStorage`).

### Чего не может JavaScript в браузере

Возможности ограничены безопасностью пользователя. Например:

- JavaScript на странице не может читать/записывать файлы на диске, копировать или запускать программы.
- Не имеет прямого доступа к функциям ОС.
- Разным вкладкам/окнам запрещено взаимодействовать друг с другом, если только они не с одного сайта (тот же протокол, домен и порт) — это называется **«Политика одинакового источника» (Same Origin Policy)**.

# Справочники и спецификации

- **Спецификация**: официальный документ ECMA-262, содержащий максимально подробное, но не всегда удобное для повседневного чтения описание JavaScript. Актуальная версия — [ecma-international.org](https://www.ecma-international.org/publications-and-standards/standards/ecma-262/).
- **MDN (Mozilla Developer Network)**: справочник с описанием отдельных функций, содержащий примеры использования и другую полезную информацию. Хорошая ссылка для быстрого поиска по конкретному методу, например по запросу «MDN parseInt».

Рекомендация: не нужно заучивать спецификацию наизусть — гораздо важнее в целом понимать возможности языка и при необходимости обращаться к справочникам.

# Редакторы кода

Редактор кода — программа, в которой удобно писать код. Два основных типа:

1. **IDE (интегрированная среда разработки)** — полноценный «комбайн» с множеством возможностей, часто работает напрямую с проектом целиком. Примеры: **Visual Studio Code**, **WebStorm**.
2. **Лёгкие редакторы** — не такие мощные, как IDE, зато быстрые, простые и хорошо настраиваемые под конкретный язык. Примеры: **Sublime Text**, **Atom**, **Notepad++**.

На практике сейчас чаще всего используется **VS Code** — бесплатный, кроссплатформенный редактор с огромным количеством расширений (подсветка синтаксиса, автодополнение, линтеры и т.д.).

# Консоль разработчика

Код может содержать ошибки, и без специальных инструментов их сложно найти. Для этого в браузерах есть **инструменты разработчика** — Developer Tools.

**Как открыть:**

- Windows/Linux: клавиша `F12` или `Ctrl+Shift+I`;
- Mac: `Cmd+Opt+I`.

Чаще всего инструменты открываются во вкладке **Console** — именно здесь показываются сообщения об ошибках и можно вводить команды JavaScript вручную для проверки.

Пример: если ввести в консоли команду с ошибкой, она будет подсвечена красным цветом с указанием строки и описанием проблемы. Также в консоли можно выполнять произвольный код:

```js
1 + 2   // после нажатия Enter консоль покажет результат: 3
```

Совет: полезно всегда держать консоль открытой во время разработки, чтобы сразу видеть ошибки.

# Основы JavaScript

## Привет, мир!

Классический первый пример при изучении любого языка программирования — вывод текста «Hello, world!».

Скрипт JavaScript можно вставить в HTML-документ почти в любом месте при помощи тега `<script>`:

```html
<!DOCTYPE HTML>
<html>

<body>

  <p>До скрипта...</p>

  <script>
    alert('Привет, мир!');
  </script>

  <p>...После скрипта.</p>

</body>

</html>
```

Тег `<script>` содержит код JavaScript, который выполняется автоматически при обработке страницы браузером.

**Современная разметка.** Тег `<script>` имеет несколько атрибутов, которые сейчас используются редко (например, `type` и `language` для старых версий языка) — в современном HTML они обычно не требуются.

**Внешние скрипты.** Если у нас много кода JavaScript, его удобно вынести в отдельный файл. Файлу скрипта присваивается расширение `.js`, и он подключается через атрибут `src`:

```html
<script src="/path/to/script.js"></script>
```

Здесь `/path/to/script.js` — абсолютный путь к файлу скрипта от корня сайта. Можно также указать относительный путь от текущей страницы, например `src="script.js"`, или полный URL:

```html
<script src="https://example.com/library.js"></script>
```

Правило: если атрибуту `src` присвоено значение, то содержимое тега `<script>` игнорируется.

Один тег `<script>` не может одновременно подключать внешний файл и содержать код внутри себя — для этого нужны два отдельных тега `<script>`.

## Структура кода

**Операторы (инструкции).** Операторы — это синтаксические конструкции и команды, выполняющие какое-либо действие.

```js
alert('Привет');
alert('Мир');
```

**Точка с запятой.** В большинстве случаев после каждой инструкции ставится точка с запятой — она не обязательна, если после инструкции идёт перевод строки, но рекомендуется всегда ставить `;` явно, чтобы избежать ошибок автоматической расстановки (ASI — Automatic Semicolon Insertion).

Пример ситуации, когда отсутствие `;` приводит к ошибке:

```js
alert("Привет")

[1, 2].forEach(alert)
```

При выполнении такого кода без `;` после первой строки JavaScript может «склеить» строки, что приведёт к ошибке, так как квадратная скобка `[` будет воспринята как обращение к элементу массива.

**Комментарии.** Комментарии не влияют на выполнение кода — они предназначены для пояснений.

- Однострочный комментарий начинается с двух слэшей `//`:

```js
// Этот комментарий занимает всю строку
alert('Привет'); // а этот комментарий следует за инструкцией
```

- Многострочный комментарий начинается со слэша со звёздочкой `/*` и заканчивается звёздочкой со слэшем `*/`:

```js
/* Пример с двумя сообщениями.
Это многострочный комментарий.
*/
alert('Привет');
alert('Мир');
```

### Строгий режим — "use strict"

До 2009 года язык JavaScript развивался без учёта обратной совместимости, и в нём накопились некоторые неудачные решения. Чтобы новые возможности языка не ломали старый код, было решено, что все нововведения (и вообще современные возможности движка) доступны только при явном включении **строгого режима**.

Строгий режим включается директивой:

```js
'use strict';
```

Директива должна находиться в самом начале скрипта или в самом начале тела функции — тогда она включит строгий режим для всего скрипта или, соответственно, только для этой функции.

```js
'use strict';

// этот код работает по современным правилам
```

Особенности:

- Директива `'use strict'` не сработает, если она находится не в начале файла (например, после каких-либо инструкций).
- В строгом режиме нельзя случайно создать глобальную переменную, не объявив её (без строгого режима такое присваивание сработало бы, создав переменную неявно).
- Все современные классы и модули JavaScript автоматически подразумевают строгий режим — в них не нужно указывать директиву отдельно.

Рекомендация: строгий режим стоит использовать всегда, так как он делает язык более предсказуемым и помогает избежать ряда типичных ошибок.

## Переменные

**Переменная** — это «именованное хранилище» для данных. Чтобы создать переменную в JavaScript, используется ключевое слово `let`.

```js
let message;

message = 'Привет'; // записываем строку

alert(message); // выводится содержимое переменной: Привет
```

Можно объявить переменную и сразу же присвоить ей значение:

```js
let message = 'Привет!';

alert(message); // Привет!
```

Можно объявить несколько переменных в одной строке:

```js
let user = 'Иван', age = 25, message = 'Привет';
```

**Повторное объявление** переменной, объявленной через `let`, приводит к ошибке — переменную с одним и тем же именем можно объявить только один раз.

**Изменение значения.** Значение переменной можно менять сколько угодно раз:

```js
let message;

message = 'Привет!';
message = 'Мир!'; // значение изменилось

alert(message); // Мир!
```

**Устаревшее слово `var`.** В старых скриптах вместо `let` можно встретить ключевое слово `var`. Оно работает похожим образом, но имеет ряд важных отличий (например, не имеет блочной области видимости). В современном коде рекомендуется использовать `let` (и `const`) вместо `var`.

**Именование переменных.** Правила для имён переменных в JavaScript:

- Имя может содержать только буквы, цифры, а также символы `$` и `_`.
- Первый символ не должен быть цифрой.
- Регистр букв имеет значение: переменные `apple` и `APPLE` — это разные переменные.
- Зарезервированные слова языка (например, `let`, `class`, `return`, `function`) нельзя использовать как имя переменной.

Правило хорошего тона — использовать понятные, описательные имена переменных, например: `userName`, `shoppingCart`.

**Константы.** Для объявления переменной, значение которой не должно изменяться, используется ключевое слово `const`:

```js
const myBirthday = '18.04.1982';

myBirthday = '01.01.2001'; // ошибка, нельзя переприсвоить константу
```

Константы, значение которых известно ещё до выполнения программы, принято записывать заглавными буквами и через знак подчёркивания:

```js
const COLOR_RED = "#F00";
const COLOR_GREEN = "#0F0";
```

## Типы данных

Переменная в JavaScript может содержать любые данные — JavaScript является **динамически типизированным** языком: типы данных существуют, но переменные не привязаны ни к одному из них.

```js
let message = "привет";
message = 123456; // тип значения изменился, ошибки нет
```

Всего в языке восемь основных типов данных.

**1. Number (число)**

Представляет как целые, так и числа с плавающей точкой:

```js
let n = 123;
n = 12.345;
```

Помимо обычных чисел, к этому типу относятся так называемые «специальные числовые значения»: `Infinity`, `-Infinity` и `NaN` (Not a Number — результат ошибки вычисления):

```js
alert(1 / 0); // Infinity
alert("не число" / 2); // NaN, деление некорректно
```

**2. BigInt (большое целое число)**

Тип `Number` не может содержать числа больше `2^53` (или меньше `-2^53`). Для работы с очень большими целыми числами используется `BigInt` — число дополняется символом `n` в конце:

```js
const bigInt = 1234567890123456789012345678901234567890n;
```

**3. String (строка)**

Строка в JavaScript должна быть заключена в кавычки:

```js
let str = "Мои строки";
let str2 = 'Одинарные кавычки тоже подходят';
let phrase = `можно вставить ${str}`; // обратные кавычки (шаблонные строки)
```

Двойные и одинарные кавычки — «простые» кавычки, разницы между ними в JavaScript нет. Обратные кавычки — «расширенная функциональность»: с их помощью можно встраивать переменные и выражения в строку, обернув их в `${…}`.

**4. Boolean (логический тип)**

Может содержать всего два значения: `true` (правда) и `false` (ложь):

```js
let nameFieldChecked = true;
let ageFieldChecked = false;
```

Такой тип часто используется для хранения значений типа «да/нет».

**5. Null**

Специальное значение, которого нет в других языках. Это отдельный тип, содержащий только значение `null`. Это не «ссылка на несуществующий объект» и не «нулевой указатель», а специальное значение, представляющее «ничего», «пусто» или «значение неизвестно».

```js
let age = null;
```

**6. Undefined**

Значение `undefined` также стоит особняком. Оно означает, что «значение не было присвоено».

```js
let age;
alert(age); // выведется "undefined"
```

**7. Object (объект)**

Единственный из всех типов данных, который не является примитивом. Объекты используются для хранения коллекций данных и более сложных сущностей.

```js
let user = {
  name: "Иван",
  age: 30
};
```

**8. Symbol (символ)**

Используется для создания уникальных идентификаторов для объектов.

**Оператор `typeof`.** Позволяет узнать тип переданного значения:

```js
typeof undefined // "undefined"
typeof 0         // "number"
typeof "foo"     // "string"
typeof true      // "boolean"
typeof null      // "object" (это ошибка языка, сохранённая для совместимости)
typeof {}        // "object"
```

### Взаимодействие: alert, prompt, confirm

Для взаимодействия со страницей браузер предоставляет ряд встроенных функций.

**alert**

Показывает окно с сообщением и ожидает, пока пользователь нажмёт «OK»:

```js
alert("Привет");
```

Мини-окно с сообщением называется **модальным**: оно не даёт пользователю взаимодействовать с остальной страницей, пока он не закроет окно.

**prompt**

Выводит окно с текстовым сообщением, полем для ввода и кнопками «OK/Отмена»:

```js
result = prompt(title, [default]);
```

- `title` — текст, который будет показан пользователю;
- `default` — необязательный второй параметр, значение по умолчанию в поле ввода.

```js
let age = prompt('Сколько вам лет?', 100);

alert(`Вам ${age} лет!`);
```

Пользователь может ввести что-то в текстовое поле и нажать «OK» — тогда значение вернётся в переменную `result`, либо отменить ввод, нажав «Отмена» — тогда вернётся `null`.

> В браузере Internet Explorer второй аргумент важно указывать всегда, иначе вместо пустой строки в поле ввода может появиться текст `"undefined"`.

**confirm**

Выводит окно с вопросом `question` и двумя кнопками: «OK» и «Отмена»:

```js
result = confirm(question);
```

Результат — `true`, если нажата кнопка «OK», и `false` — в случае нажатия «Отмена» или клавиши `Esc`:

```js
let isBoss = confirm("Вы здесь главный?");

alert(isBoss); // true, если нажата OK
```

**Общая черта всех трёх функций (alert, prompt, confirm):** окна являются модальными — они приостанавливают выполнение скрипта и не дают взаимодействовать с остальной страницей, пока пользователь не закроет окно. Также место расположения окна и его внешний вид определяются браузером — изменить это средствами JavaScript нельзя.


## 1. Преобразование типов

**Преобразование типов** — это приведение значения одного типа к другому. Большинство операторов и функций автоматически преобразуют переданные значения к нужному типу (**неявное преобразование**). Также можно преобразовать значение вручную (**явное преобразование**).

Примитивные типы: `string`, `number`, `boolean`, `null`, `undefined`, `bigint`, `symbol`.

### 1.1. Строковое преобразование

Происходит, когда значение выводится (например, через `alert`) или при вызове `String(value)`.

```js
let value = true;
alert(typeof value); // boolean

value = String(value);
alert(typeof value); // string, значение "true"

alert(String(123));   // "123"
alert(String(null));  // "null"
```

### 1.2. Численное преобразование

Происходит в математических функциях и выражениях, а также при вызове `Number(value)`.

```js
alert("6" / "2");        // 3, строки преобразуются в числа

let str = "123";
let num = Number(str);   // 123
alert(typeof num);       // number

let age = Number("hello"); // NaN, преобразование не удалось
```

Правила численного преобразования:

- `undefined` становится `NaN`
- `null` становится `0`
- `true` и `false` становятся `1` и `0`
- Строка: пробелы по краям удаляются. Пустая строка становится `0`. Если строка не является числом, результат `NaN`

```js
alert(Number("   123   ")); // 123
alert(Number("123z"));      // NaN
alert(Number(true));        // 1
alert(Number(false));       // 0
alert(Number(null));        // 0
alert(Number(undefined));   // NaN
```

Важно: `null` и `undefined` ведут себя по-разному. `null` становится `0`, а `undefined` становится `NaN`.

Унарный плюс `+` тоже преобразует значение в число: `+"5"` даёт `5`.

### 1.3. Логическое преобразование

Происходит в логических операциях и при вызове `Boolean(value)`.

Правила:

- Значения, которые интуитивно «пустые» (`0`, пустая строка, `null`, `undefined`, `NaN`), становятся `false`
- Все остальные значения становятся `true`

```js
alert(Boolean(1));         // true
alert(Boolean(0));         // false
alert(Boolean("hello"));   // true
alert(Boolean(""));        // false
alert(Boolean("0"));       // true, непустая строка
alert(Boolean(" "));       // true, пробел тоже символ
```

Важно: строка `"0"` даёт `true`, а число `0` даёт `false`.

## 2. Базовые операторы, математика

**Операнд** — то, к чему применяется оператор. Например, в `5 * 2` два операнда: `5` и `2`.

**Унарный** оператор применяется к одному операнду (`-x`). **Бинарный** оператор применяется к двум операндам (`x - y`).

### 2.1. Математические операторы

- `+` сложение
- `-` вычитание
- `*` умножение
- `/` деление
- `%` остаток от деления
- `**` возведение в степень

```js
alert(5 % 2);   // 1, остаток от деления 5 на 2
alert(8 % 3);   // 2
alert(2 ** 3);  // 8, то есть 2 * 2 * 2
alert(4 ** (1/2)); // 2, квадратный корень
```

### 2.2. Сложение строк через бинарный `+`

Если хотя бы один операнд является строкой, то второй тоже преобразуется в строку.

```js
alert("1" + 2);   // "12"
alert(2 + "1");   // "21"
alert(2 + 2 + "1"); // "41", вычисления идут слева направо
alert("1" + 2 + 2); // "122"
```

Остальные математические операторы всегда приводят операнды к числам:

```js
alert(6 - "2");   // 4
alert("6" / "2"); // 3
```

### 2.3. Унарный плюс

Унарный `+` преобразует значение в число, ничего не меняя для чисел.

```js
let apples = "2";
let oranges = "3";

alert(apples + oranges);   // "23", строки склеиваются
alert(+apples + +oranges); // 5, значения преобразованы в числа
```

### 2.4. Приоритет операторов

Если в выражении несколько операторов, порядок выполнения определяется приоритетом. Умножение и деление выполняются раньше сложения и вычитания. Скобки имеют наивысший приоритет. Унарные операторы приоритетнее бинарных. Присваивание имеет очень низкий приоритет.

```js
alert(2 + 2 * 2);   // 6
alert((2 + 2) * 2); // 8
```

### 2.5. Присваивание

Присваивание `=` возвращает значение, поэтому его можно использовать в цепочке.

```js
let a, b, c;
a = b = c = 2 + 2;
alert(a); // 4
alert(b); // 4
alert(c); // 4
```

### 2.6. Сокращённая арифметика с присваиванием

```js
let n = 2;
n += 5; // n = n + 5, теперь 7
n *= 2; // n = n * 2, теперь 14
```

### 2.7. Инкремент и декремент

- `++` увеличивает переменную на 1
- `--` уменьшает переменную на 1

Применяются только к переменным.

```js
let counter = 2;
counter++; // 3
counter--; // 2
```

Префиксная форма (`++counter`) возвращает новое значение. Постфиксная форма (`counter++`) возвращает старое значение.

```js
let a = 1;
alert(++a); // 2

let b = 1;
alert(b++); // 1, а затем b становится 2
```

### 2.8. Побитовые операторы

Работают с аргументами как с 32-разрядными целыми числами: `&` (И), `|` (ИЛИ), `^` (исключающее ИЛИ), `~` (НЕ), `<<`, `>>`, `>>>` (сдвиги).

### 2.9. Оператор запятая

Позволяет вычислить несколько выражений через запятую. Возвращается результат только последнего.

```js
let a = (1 + 2, 3 + 4);
alert(a); // 7
```

## 3. Операторы сравнения

Операторы:

- `>` больше, `<` меньше
- `>=` больше или равно, `<=` меньше или равно
- `==` равно (нестрогое), `!=` не равно (нестрогое)
- `===` строго равно, `!==` строго не равно

Результат сравнения всегда имеет логический тип (`true` или `false`).

```js
alert(2 > 1);  // true
alert(2 == 1); // false
alert(2 != 1); // true
```

### 3.1. Сравнение строк

Строки сравниваются посимвольно в лексикографическом (алфавитном) порядке, согласно кодам символов Unicode.

```js
alert("Я" > "А");     // true
alert("Коты" > "Кода"); // true
alert("Сонный" > "Сон"); // true, более длинная строка больше
alert("a" > "A");     // true, строчные буквы больше заглавных
```

### 3.2. Сравнение разных типов

При сравнении значений разных типов JavaScript преобразует их в числа.

```js
alert("2" > 1);   // true, строка "2" становится числом 2
alert("01" == 1); // true
alert(true == 1); // true
alert(false == 0); // true
```

Возможна странная ситуация: два значения равны, но одно из них как логическое `true`, а другое `false`.

```js
let a = 0;
alert(Boolean(a)); // false

let b = "0";
alert(Boolean(b)); // true

alert(a == b);     // true
```

### 3.3. Строгое сравнение

Обычное равенство `==` не отличает `0` от `false`, так как оба значения преобразуются в число. Строгое равенство `===` проверяет равенство без приведения типов. Если типы разные, то результат `false`.

```js
alert(0 == false);  // true
alert("" == false); // true

alert(0 === false); // false, разные типы
```

Для неравенства есть строгий аналог `!==`.

### 3.4. Сравнение с null и undefined

Строгое равенство: типы разные, поэтому `false`.

```js
alert(null === undefined); // false
```

Нестрогое равенство: `null` и `undefined` равны друг другу и не равны ничему другому.

```js
alert(null == undefined); // true
```

При сравнении через `>`, `<`, `>=`, `<=` значения `null` и `undefined` преобразуются в числа: `null` становится `0`, `undefined` становится `NaN`.

```js
alert(null > 0);  // false
alert(null == 0); // false
alert(null >= 0); // true
```

Значение `undefined` нельзя сравнивать с другими значениями (кроме `null`):

```js
alert(undefined > 0);  // false
alert(undefined < 0);  // false
alert(undefined == 0); // false
```

Рекомендация: относиться к любому сравнению с `undefined` и `null` (кроме строгого равенства) с осторожностью.

## 4. Условное ветвление: `if`, `?`

### 4.1. Оператор `if`

Оператор `if (...)` вычисляет условие в скобках и преобразует результат к логическому типу. Если результат `true`, выполняется блок кода.

```js
let year = prompt("В каком году появился стандарт ECMAScript-2015?", "");

if (year == 2015) alert("Вы правы!");
```

Если действий несколько, их заключают в фигурные скобки:

```js
if (year == 2015) {
  alert("Правильно!");
  alert("Вы такой умный!");
}
```

Рекомендуется использовать фигурные скобки всегда, даже если команда одна.

### 4.2. Преобразование к логическому типу в условии

- Число `0`, пустая строка `""`, `null`, `undefined` и `NaN` становятся `false`
- Остальные значения становятся `true`

```js
if (0) {
  // не выполнится
}

if (1) {
  // выполнится
}
```

### 4.3. Блок `else`

Необязательный блок `else` выполняется, если условие ложно.

```js
if (year == 2015) {
  alert("Да вы знаток!");
} else {
  alert("Как вы можете так ошибаться?");
}
```

### 4.4. Несколько условий: `else if`

```js
if (year < 2015) {
  alert("Это слишком рано...");
} else if (year > 2015) {
  alert("Это поздновато");
} else {
  alert("Верно!");
}
```

### 4.5. Условный оператор `?` (тернарный)

Позволяет записать условие короче. Синтаксис:

```js
let result = условие ? значение1 : значение2;
```

Сначала вычисляется условие. Если оно истинно, возвращается `значение1`, иначе `значение2`.

```js
let accessAllowed = age > 18 ? true : false;
// Здесь можно и проще: let accessAllowed = age > 18;
```

### 4.6. Несколько операторов `?`

Последовательность операторов `?` позволяет вернуть значение, которое зависит от нескольких условий.

```js
let age = prompt("возраст?", 18);

let message = age < 3 ? "Здравствуй, малыш!" :
  age < 18 ? "Привет!" :
  age < 100 ? "Здравствуйте!" :
  "Какой необычный возраст!";

alert(message);
```

### 4.7. Нетрадиционное использование `?`

Оператор `?` не рекомендуется использовать вместо `if` для выполнения разных действий. Он предназначен для возврата значения, а `if` — для управления потоком выполнения.

```js
// Плохо читается
(company == "Netscape") ? alert("Верно!") : alert("Неверно.");

// Лучше
if (company == "Netscape") {
  alert("Верно!");
} else {
  alert("Неверно.");
}
```

## 5. Логические операторы

В JavaScript есть четыре логических оператора:

- `||` (ИЛИ)
- `&&` (И)
- `!` (НЕ)
- `??` (оператор нулевого слияния, рассматривается в следующем разделе)

Несмотря на название, они могут применяться к значениям любого типа, а результат также может быть любого типа.

### 5.1. `||` (ИЛИ)

Результат `true`, если хотя бы один аргумент `true`.

```js
alert(true || true);   // true
alert(false || true);  // true
alert(true || false);  // true
alert(false || false); // false
```

Если операнд не логического типа, он преобразуется в логический для вычислений.

```js
if (1 || 0) {
  alert("truthy!"); // сработает
}
```

### 5.2. Поиск первого истинного значения

Оператор `||` выполняет следующее:

1. Вычисляет операнды слева направо
2. Каждый операнд преобразует в логическое значение. Если результат `true`, останавливается и возвращает исходное значение этого операнда
3. Если все операнды ложны, возвращает последний из них

```js
alert(1 || 0);                    // 1
alert(null || 1);                 // 1
alert(null || 0 || 1);            // 1
alert(undefined || null || 0);    // 0, последнее значение
```

Применение: получение первого истинного значения из списка переменных или выражений.

```js
let firstName = "";
let lastName = "";
let nickName = "СуперКодер";

alert(firstName || lastName || nickName || "Аноним"); // СуперКодер
```

### 5.3. Сокращённое вычисление

Операнды вычисляются до первого истинного. Остальные не вычисляются, если результат уже понятен.

```js
true || alert("не напечатана");
false || alert("напечатана");
```

### 5.4. `&&` (И)

Результат `true`, если оба аргумента `true`.

```js
alert(true && true);   // true
alert(false && true);  // false
alert(true && false);  // false
alert(false && false); // false
```

```js
let hour = 12;
let minute = 30;

if (hour == 12 && minute == 30) {
  alert("Время 12:30");
}
```

### 5.5. Поиск первого ложного значения

Оператор `&&` выполняет следующее:

1. Вычисляет операнды слева направо
2. Каждый операнд преобразует в логическое значение. Если результат `false`, останавливается и возвращает исходное значение этого операнда
3. Если все операнды истинны, возвращает последний из них

```js
alert(1 && 0);          // 0
alert(1 && 5);          // 5
alert(null && 5);       // null
alert(1 && 2 && null && 3); // null
alert(1 && 2 && 3);     // 3, последнее значение
```

Приоритет оператора `&&` выше, чем у `||`.

Не рекомендуется заменять `if` операторами `||` и `&&`, так как это ухудшает читаемость.

### 5.6. `!` (НЕ)

Принимает один аргумент. Выполняет:

1. Преобразует операнд к логическому типу
2. Возвращает противоположное значение

```js
alert(!true);  // false
alert(!0);     // true
```

Двойное отрицание `!!` используется для преобразования значения в логический тип (то же, что и `Boolean`):

```js
alert(!!"непустая строка"); // true
alert(!!null);              // false
```

Приоритет `!` — самый высокий из всех логических операторов.

## 6. Операторы нулевого слияния и присваивания: `??`, `??=`

### 6.1. Оператор нулевого слияния `??`

Результат выражения `a ?? b`:

- `a`, если значение `a` определено (не `null` и не `undefined`)
- `b` в противном случае

Эквивалентная запись:

```js
result = (a !== null && a !== undefined) ? a : b;
```

Пример: показать имя пользователя, а если оно не задано, показать «Аноним».

```js
let user;

alert(user ?? "Аноним"); // Аноним, так как user не определён

user = "Иван";
alert(user ?? "Аноним"); // Иван
```

Можно использовать последовательность из нескольких значений. Берётся первое, которое не равно `null` или `undefined`.

```js
let firstName = null;
let lastName = null;
let nickName = "Суперкодер";

alert(firstName ?? lastName ?? nickName ?? "Аноним"); // Суперкодер
```

### 6.2. Сравнение `??` и `||`

Главное отличие:

- `||` возвращает первое истинное значение
- `??` возвращает первое определённое значение (не `null` и не `undefined`)

То есть `||` не различает `false`, `0`, пустую строку `""` и `null/undefined`: все они считаются ложными. А `??` считает «пустыми» только `null` и `undefined`.

```js
let height = 0;

alert(height || 100); // 100, так как 0 считается ложным
alert(height ?? 100); // 0, так как 0 определено
```

Вывод: если нужно подставить значение по умолчанию только при отсутствии значения, лучше использовать `??`.

### 6.3. Приоритет

Приоритет `??` довольно низкий. Он выше `=` и `?`, но ниже большинства других операторов (`+`, `*` и так далее). Поэтому может потребоваться добавление скобок.

```js
let height = null;
let width = null;

let area = (height ?? 100) * (width ?? 50);
alert(area); // 5000
```

### 6.4. Запрет на использование с `||` и `&&`

Из соображений безопасности JavaScript запрещает использовать `??` вместе с `&&` и `||` без явных скобок.

```js
// let x = 1 && 2 ?? 3; // Ошибка синтаксиса

let x = (1 && 2) ?? 3; // Так работает
alert(x); // 2
```

### 6.5. Оператор присваивания нулевого слияния `??=`

Присваивает значение переменной, только если она равна `null` или `undefined`.

```js
let user = { name: null };

user.name ??= "Аноним";
alert(user.name); // Аноним

user.name ??= "Иван";
alert(user.name); // Аноним, значение уже определено
```

Запись `a ??= b` равносильна `a = a ?? b`, то есть присваивание происходит только когда `a` пусто.

Похожие операторы: `||=` (присвоить, если значение ложно) и `&&=` (присвоить, если значение истинно).

```js
let a = 0;
a ||= 10;
alert(a); // 10, так как 0 ложно

let b = 0;
b ??= 10;
alert(b); // 0, так как 0 определено
```


## Циклы while и for

**Цикл** — это конструкция языка, которая позволяет многократно выполнять один и тот же блок кода (тело цикла). Один проход по телу цикла называется **итерацией**.

### Цикл while

Цикл `while` выполняет тело, пока **условие** (выражение, приводимое к логическому типу) остаётся истинным. Условие проверяется **перед** каждой итерацией, поэтому если оно изначально ложно, тело не выполнится ни разу.

```javascript
let i = 0;
while (i < 3) {
  console.log(i); // 0, 1, 2
  i++;
}
```

Любое значение, приводимое к `true`, запускает итерацию. Значения, приводимые к `false`: `0`, `""`, `null`, `undefined`, `NaN`, `false`.

### Цикл do...while

Цикл `do...while` — это **цикл с постусловием**: сначала выполняется тело, и только потом проверяется условие. Тело гарантированно выполнится минимум один раз.

```javascript
let j = 0;
do {
  console.log(j);
  j++;
} while (j < 3);
```

### Цикл for

Цикл `for` — самый часто используемый **цикл со счётчиком**. Его синтаксис состоит из трёх частей:

- **начало** (`let i = 0`) — выполняется один раз перед входом в цикл;
- **условие** (`i < 3`) — проверяется перед каждой итерацией;
- **шаг** (`i++`) — выполняется после тела на каждой итерации.

```javascript
for (let i = 0; i < 3; i++) {
  console.log(i); // 0, 1, 2
}
```

Любую часть заголовка `for` можно пропустить, но точки с запятой обязательны:

```javascript
let k = 0;
for (; k < 3; ) {
  k++;
}
```

Переменная, объявленная через `let` внутри заголовка, видна **только внутри цикла** (область видимости блока).

### Директивы break и continue

- **break** — немедленно прерывает весь цикл и передаёт управление коду после него.
- **continue** — прерывает только текущую итерацию и переходит к следующей.

```javascript
for (let i = 0; i < 10; i++) {
  if (i === 3) continue; // пропустить 3
  if (i === 6) break;    // выйти из цикла
  console.log(i);        // 0, 1, 2, 4, 5
}
```

Директивы `break` и `continue` нельзя использовать справа от оператора `?`, так как это не выражения, а **инструкции**.

### Метки для break и continue

**Метка** — это идентификатор с двоеточием перед циклом. Она позволяет выйти сразу из нескольких вложенных циклов.

```javascript
outer: for (let i = 0; i < 3; i++) {
  for (let j = 0; j < 3; j++) {
    if (i === 1 && j === 1) break outer;
    console.log(i, j);
  }
}
```

## Конструкция "switch"

Конструкция `switch` заменяет собой несколько проверок `if` и является более наглядным способом **сравнить выражение сразу с несколькими вариантами**.

Она содержит один или более блоков `case` и необязательный блок `default`. Значение выражения сравнивается со значениями из `case` при помощи **строгого равенства** (`===`), поэтому типы должны совпадать.

```javascript
let day = 3;

switch (day) {
  case 1:
    console.log("Понедельник");
    break;
  case 2:
    console.log("Вторник");
    break;
  case 3:
    console.log("Среда");
    break;
  default:
    console.log("Другой день");
}
```

Важные особенности:

- Если `break` отсутствует, выполнение **провалится** (fall through) в следующий `case` без проверки условия.
- Блок `default` выполняется, если ни один `case` не подошёл.
- Несколько `case` можно **группировать**, чтобы выполнить один и тот же код.
- И `switch`, и `case` допускают **любые выражения**, а не только константы.

```javascript
let a = 2;

switch (a) {
  case 1:
  case 2: // группировка: сработает для 1 и для 2
    console.log("Один или два");
    break;
  default:
    console.log("Что-то другое");
}
```

## Функции

**Функция** — это именованный блок кода, который можно вызывать многократно из разных мест программы. Функции — главные «строительные блоки» программы, они позволяют избежать дублирования кода.

### Объявление функции (Function Declaration)

```javascript
function showMessage() {
  console.log("Всем привет!");
}

showMessage(); // вызов функции
```

Ключевое слово `function` идёт первым, затем **имя функции**, список **параметров** в скобках и **тело функции** в фигурных скобках.

### Локальные и внешние переменные

- **Локальная переменная** объявлена внутри функции и видна только в ней.
- **Внешняя (глобальная) переменная** объявлена снаружи и доступна внутри функции; функция может её читать и изменять.

```javascript
let userName = "Вася"; // внешняя переменная

function greet() {
  let message = "Привет, " + userName; // message — локальная
  console.log(message);
}

greet(); // Привет, Вася
```

Если внутри функции объявлена переменная с тем же именем, что и внешняя, то **внутренняя затеняет внешнюю**.

### Параметры и аргументы

**Параметр** — переменная, указанная в объявлении функции. **Аргумент** — значение, переданное при вызове. Аргументы передаются **по значению**: функция работает с копией.

```javascript
function sum(a, b) {
  return a + b;
}

console.log(sum(2, 3)); // 5
```

### Значения по умолчанию

Если аргумент не передан, соответствующий параметр получает значение `undefined`. Для него можно задать **значение по умолчанию**:

```javascript
function showMessage(from, text = "текст не добавлен") {
  console.log(from + ": " + text);
}

showMessage("Аня");               // Аня: текст не добавлен
showMessage("Аня", "Привет!");    // Аня: Привет!
```

### Возврат значения

Директива `return` завершает выполнение функции и возвращает результат в место вызова. Если `return` отсутствует или указан без значения, функция возвращает `undefined`.

```javascript
function checkAge(age) {
  if (age >= 18) {
    return true;
  }
  return false;
}
```

После `return` нельзя переносить значение на новую строку: интерпретатор автоматически поставит точку с запятой и вернёт `undefined`.

### Выбор имени функции

Функция — это действие, поэтому её имя обычно **глагол**. Принято использовать префиксы:

- `show...` — показать что-то;
- `get...` — вернуть значение;
- `calc...` — вычислить;
- `create...` — создать;
- `check...` — проверить и вернуть логическое значение.

Одна функция должна выполнять **ровно одно действие**.

## Function Expression

**Function Expression** (функциональное выражение) — это ещё один синтаксис создания функции, при котором функция создаётся внутри выражения и присваивается переменной.

```javascript
let sayHi = function () {
  console.log("Привет");
};

sayHi();
```

Функция в JavaScript — это **особое значение** (объект), поэтому её можно копировать, передавать и присваивать, как любое другое значение:

```javascript
function sayHello() {
  console.log("Hello");
}

let func = sayHello; // копируем ссылку на функцию (без скобок!)
func();              // Hello
sayHello();          // Hello
```

Если написать `sayHello()` со скобками, функция будет **вызвана**, а в переменную попадёт её результат.

### Функции-колбэки

**Колбэк (callback)** — это функция, которая передаётся в другую функцию как аргумент и должна быть вызвана позже, «обратно».

```javascript
function ask(question, yes, no) {
  if (confirm(question)) yes();
  else no();
}

ask(
  "Вы согласны?",
  function () { console.log("Вы согласились."); },
  function () { console.log("Вы отменили выполнение."); }
);
```

### Отличия Function Expression от Function Declaration

1. **Время создания.** Function Declaration можно вызвать **до** её объявления в коде (благодаря *поднятию*, hoisting — движок создаёт такие функции заранее при подготовке скрипта). Function Expression создаётся только тогда, когда до неё дойдёт выполнение.
2. **Область видимости.** В строгом режиме Function Declaration, объявленная внутри блока `{...}`, видна только внутри этого блока.
3. **Синтаксис.** Function Declaration — отдельная инструкция, Function Expression — часть выражения, поэтому после неё ставится точка с запятой.

```javascript
sayHi("Вася"); // работает: Function Declaration поднимается

function sayHi(name) {
  console.log("Привет, " + name);
}

// sayBye("Вася"); // ошибка: переменная ещё не получила значение
let sayBye = function (name) {
  console.log("Пока, " + name);
};
```

Рекомендуется сначала рассматривать синтаксис Function Declaration: он даёт больше свободы в организации кода, так как функции можно вызывать до их объявления.

## Стрелочные функции, основы

**Стрелочные функции** — это простой и краткий синтаксис создания функций, часто более удобный, чем Function Expression.

### Синтаксис

```javascript
let func = (arg1, arg2, ...argN) => expression;
```

Это эквивалент записи:

```javascript
let func = function (arg1, arg2, ...argN) {
  return expression;
};
```

Пример:

```javascript
let sum = (a, b) => a + b;

console.log(sum(1, 2)); // 3
```

### Особенности записи

- Если аргумент **один**, круглые скобки можно опустить: `let double = n => n * 2;`
- Если аргументов **нет**, скобки обязательны: `let sayHi = () => console.log("Привет");`
- Стрелочные функции можно использовать так же, как и Function Expression, в том числе как колбэки.

```javascript
let age = 20;

let welcome = age < 18
  ? () => console.log("Привет")
  : () => console.log("Здравствуйте!");

welcome();
```

### Многострочные стрелочные функции

Если требуется несколько инструкций, тело оборачивают в **фигурные скобки** и обязательно используют явный `return`:

```javascript
let sum = (a, b) => {
  let result = a + b;
  return result;
};

console.log(sum(1, 2)); // 3
```

### Возврат объекта

Чтобы вернуть объектный литерал, его нужно обернуть в круглые скобки, иначе фигурные скобки будут восприняты как тело функции:

```javascript
let makeUser = name => ({ name: name, active: true });
```

## Особенности JavaScript

### Общая характеристика

- **JavaScript** был создан для добавления интерактивности на веб-страницы. Изначально назывался LiveScript, а название JavaScript получил из маркетинговых соображений. К языку Java он не имеет прямого отношения.
- Язык описан стандартом **ECMAScript** (ES), поэтому говорят о версиях ES5, ES6 (ES2015) и последующих ежегодных обновлениях.
- Код выполняется в **движке** — программе, встроенной в браузер (например, V8 в Chrome) или в платформу **Node.js** для работы на сервере.
- Язык **интерпретируемый**, но современные движки используют **JIT-компиляцию** (Just-In-Time) — компиляцию кода в машинный в процессе выполнения для ускорения работы.

### Динамическая типизация

Переменная не привязана к определённому типу, её значение может менять тип во время выполнения программы:

```javascript
let value = 42;       // number
value = "строка";     // string
value = true;         // boolean
```

В JavaScript существует **восемь типов данных**: `number`, `bigint`, `string`, `boolean`, `null`, `undefined`, `symbol` (примитивные) и `object` (ссылочный). Оператор `typeof` позволяет определить тип значения.

### Приведение типов

Язык автоматически выполняет **неявное приведение типов**, что бывает неожиданным:

```javascript
console.log("5" + 2);  // "52" (строка)
console.log("5" - 2);  // 3 (число)
console.log(0 == "");  // true (нестрогое равенство)
console.log(0 === ""); // false (строгое равенство)
```

Поэтому рекомендуется использовать **строгое сравнение** `===` и `!==`.

### Однопоточность и событийная модель

JavaScript **однопоточный**: в каждый момент времени выполняется только одна операция. Асинхронность достигается за счёт **цикла событий** (event loop), **очереди задач** и механизмов вроде `setTimeout`, промисов и `async/await`.

### Функции как значения первого класса

Функции можно присваивать переменным, передавать как аргументы, возвращать из других функций и хранить в объектах. Это основа **функционального стиля** программирования и **замыканий** (closure) — способности функции помнить окружение, в котором она была создана.

### Прототипное наследование

В отличие от классических языков, JavaScript использует **прототипную модель наследования**: у объекта есть скрытая ссылка `[[Prototype]]` на другой объект, из которого он наследует свойства и методы. Синтаксис `class` — это более удобная запись поверх прототипов.

### Строгий режим

Директива `"use strict";` в начале скрипта или функции включает **строгий режим**, который запрещает некоторые небезопасные конструкции (например, использование необъявленных переменных) и выбрасывает ошибки вместо тихого игнорирования проблем. В современных модулях и классах строгий режим включён по умолчанию.

```javascript
"use strict";

x = 5; // ReferenceError: x is not defined
```

### Ограничения в браузере

Из соображений безопасности JavaScript в браузере **не имеет прямого доступа** к файловой системе, ограничен политикой одинакового источника (**Same-Origin Policy**) и может обращаться к другим сайтам только через механизмы вроде CORS.

### Совместимость и транспиляция

Новые возможности языка могут не поддерживаться старыми браузерами. Для решения этой проблемы используют:

- **транспайлеры** (например, Babel) — переводят современный синтаксис в старый;
- **полифилы** — добавляют недостающие функции, реализуя их средствами самого языка.
