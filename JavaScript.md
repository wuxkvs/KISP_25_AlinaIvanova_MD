# Введение в JavaScript

**JavaScript** — язык программирования, который изначально создавался для того, чтобы «оживлять» веб-страницы: делать их интерактивными.

Особенности JavaScript:

- Полностью интегрирован с HTML/CSS.
- Простые вещи делаются просто.
- Поддерживается всеми основными браузерами и включён по умолчанию.

JavaScript — это **язык браузера**, но сегодня он используется гораздо шире:

- на серверах (например, платформа **Node.js**);
- в мобильной разработке (React Native, NativeScript);
- на «умных» устройствах и в десктопных приложениях (Electron).

> Важно: в браузере у JavaScript есть ограничения (в целях безопасности), которых нет у серверного JavaScript. Например, обычный скрипт в браузере не может напрямую читать файлы на диске пользователя без его явного разрешения.

### Что такое движок JavaScript?

Движок (engine) — это программа, которая исполняет код JavaScript. Каждый браузер имеет свой движок:

- Chrome, Opera — **V8**;
- Firefox — **SpiderMonkey**;
- Safari — **JavaScriptCore (Nitro)**.

Принцип работы движка:
1. Движок (встроенный в браузер, если речь о браузере) читает («парсит») скрипт.
2. Затем преобразовывает («компилирует») скрипт в машинный код.
3. Машинный код запускается на выполнение.

### Что может JavaScript в браузере

- Добавлять HTML-разметку на страницу, изменять содержимое, менять стили.
- Реагировать на действия пользователя: клики мыши, движение курсора, нажатия клавиш.
- Посылать запросы на сервер без перезагрузки страницы (AJAX).
- Получать и устанавливать cookie, задавать вопросы посетителю, показывать сообщения.
- Запоминать данные на стороне клиента (`localStorage`).

### Чего не может JavaScript в браузере

Возможности ограничены безопасностью пользователя. Например:

- JavaScript на странице не может читать/записывать файлы на диске, копировать или запускать программы.
- Не имеет прямого доступа к функциям ОС.
- Разным вкладкам/окнам запрещено взаимодействовать друг с другом, если только они не с одного сайта (тот же протокол, домен и порт) — это называется **«Политика одинакового источника» (Same Origin Policy)**.

# Справочники и спецификации

- **Спецификация**: официальный документ ECMA-262, содержащий максимально подробное, но не всегда удобное для повседневного чтения описание JavaScript. Актуальная версия — [ecma-international.org](https://www.ecma-international.org/publications-and-standards/standards/ecma-262/).
- **MDN (Mozilla Developer Network)**: справочник с описанием отдельных функций, содержащий примеры использования и другую полезную информацию. Хорошая ссылка для быстрого поиска по конкретному методу, например по запросу «MDN parseInt».

Рекомендация: не нужно заучивать спецификацию наизусть — гораздо важнее в целом понимать возможности языка и при необходимости обращаться к справочникам.

# Редакторы кода

Редактор кода — программа, в которой удобно писать код. Два основных типа:

1. **IDE (интегрированная среда разработки)** — полноценный «комбайн» с множеством возможностей, часто работает напрямую с проектом целиком. Примеры: **Visual Studio Code**, **WebStorm**.
2. **Лёгкие редакторы** — не такие мощные, как IDE, зато быстрые, простые и хорошо настраиваемые под конкретный язык. Примеры: **Sublime Text**, **Atom**, **Notepad++**.

На практике сейчас чаще всего используется **VS Code** — бесплатный, кроссплатформенный редактор с огромным количеством расширений (подсветка синтаксиса, автодополнение, линтеры и т.д.).

# Консоль разработчика

Код может содержать ошибки, и без специальных инструментов их сложно найти. Для этого в браузерах есть **инструменты разработчика** — Developer Tools.

**Как открыть:**

- Windows/Linux: клавиша `F12` или `Ctrl+Shift+I`;
- Mac: `Cmd+Opt+I`.

Чаще всего инструменты открываются во вкладке **Console** — именно здесь показываются сообщения об ошибках и можно вводить команды JavaScript вручную для проверки.

Пример: если ввести в консоли команду с ошибкой, она будет подсвечена красным цветом с указанием строки и описанием проблемы. Также в консоли можно выполнять произвольный код:

```js
1 + 2   // после нажатия Enter консоль покажет результат: 3
```

Совет: полезно всегда держать консоль открытой во время разработки, чтобы сразу видеть ошибки.

# Основы JavaScript

## Привет, мир!

Классический первый пример при изучении любого языка программирования — вывод текста «Hello, world!».

Скрипт JavaScript можно вставить в HTML-документ почти в любом месте при помощи тега `<script>`:

```html
<!DOCTYPE HTML>
<html>

<body>

  <p>До скрипта...</p>

  <script>
    alert('Привет, мир!');
  </script>

  <p>...После скрипта.</p>

</body>

</html>
```

Тег `<script>` содержит код JavaScript, который выполняется автоматически при обработке страницы браузером.

**Современная разметка.** Тег `<script>` имеет несколько атрибутов, которые сейчас используются редко (например, `type` и `language` для старых версий языка) — в современном HTML они обычно не требуются.

**Внешние скрипты.** Если у нас много кода JavaScript, его удобно вынести в отдельный файл. Файлу скрипта присваивается расширение `.js`, и он подключается через атрибут `src`:

```html
<script src="/path/to/script.js"></script>
```

Здесь `/path/to/script.js` — абсолютный путь к файлу скрипта от корня сайта. Можно также указать относительный путь от текущей страницы, например `src="script.js"`, или полный URL:

```html
<script src="https://example.com/library.js"></script>
```

Правило: если атрибуту `src` присвоено значение, то содержимое тега `<script>` игнорируется.

Один тег `<script>` не может одновременно подключать внешний файл и содержать код внутри себя — для этого нужны два отдельных тега `<script>`.

## Структура кода

**Операторы (инструкции).** Операторы — это синтаксические конструкции и команды, выполняющие какое-либо действие.

```js
alert('Привет');
alert('Мир');
```

**Точка с запятой.** В большинстве случаев после каждой инструкции ставится точка с запятой — она не обязательна, если после инструкции идёт перевод строки, но рекомендуется всегда ставить `;` явно, чтобы избежать ошибок автоматической расстановки (ASI — Automatic Semicolon Insertion).

Пример ситуации, когда отсутствие `;` приводит к ошибке:

```js
alert("Привет")

[1, 2].forEach(alert)
```

При выполнении такого кода без `;` после первой строки JavaScript может «склеить» строки, что приведёт к ошибке, так как квадратная скобка `[` будет воспринята как обращение к элементу массива.

**Комментарии.** Комментарии не влияют на выполнение кода — они предназначены для пояснений.

- Однострочный комментарий начинается с двух слэшей `//`:

```js
// Этот комментарий занимает всю строку
alert('Привет'); // а этот комментарий следует за инструкцией
```

- Многострочный комментарий начинается со слэша со звёздочкой `/*` и заканчивается звёздочкой со слэшем `*/`:

```js
/* Пример с двумя сообщениями.
Это многострочный комментарий.
*/
alert('Привет');
alert('Мир');
```

### Строгий режим — "use strict"

До 2009 года язык JavaScript развивался без учёта обратной совместимости, и в нём накопились некоторые неудачные решения. Чтобы новые возможности языка не ломали старый код, было решено, что все нововведения (и вообще современные возможности движка) доступны только при явном включении **строгого режима**.

Строгий режим включается директивой:

```js
'use strict';
```

Директива должна находиться в самом начале скрипта или в самом начале тела функции — тогда она включит строгий режим для всего скрипта или, соответственно, только для этой функции.

```js
'use strict';

// этот код работает по современным правилам
```

Особенности:

- Директива `'use strict'` не сработает, если она находится не в начале файла (например, после каких-либо инструкций).
- В строгом режиме нельзя случайно создать глобальную переменную, не объявив её (без строгого режима такое присваивание сработало бы, создав переменную неявно).
- Все современные классы и модули JavaScript автоматически подразумевают строгий режим — в них не нужно указывать директиву отдельно.

Рекомендация: строгий режим стоит использовать всегда, так как он делает язык более предсказуемым и помогает избежать ряда типичных ошибок.

## Переменные

**Переменная** — это «именованное хранилище» для данных. Чтобы создать переменную в JavaScript, используется ключевое слово `let`.

```js
let message;

message = 'Привет'; // записываем строку

alert(message); // выводится содержимое переменной: Привет
```

Можно объявить переменную и сразу же присвоить ей значение:

```js
let message = 'Привет!';

alert(message); // Привет!
```

Можно объявить несколько переменных в одной строке:

```js
let user = 'Иван', age = 25, message = 'Привет';
```

**Повторное объявление** переменной, объявленной через `let`, приводит к ошибке — переменную с одним и тем же именем можно объявить только один раз.

**Изменение значения.** Значение переменной можно менять сколько угодно раз:

```js
let message;

message = 'Привет!';
message = 'Мир!'; // значение изменилось

alert(message); // Мир!
```

**Устаревшее слово `var`.** В старых скриптах вместо `let` можно встретить ключевое слово `var`. Оно работает похожим образом, но имеет ряд важных отличий (например, не имеет блочной области видимости). В современном коде рекомендуется использовать `let` (и `const`) вместо `var`.

**Именование переменных.** Правила для имён переменных в JavaScript:

- Имя может содержать только буквы, цифры, а также символы `$` и `_`.
- Первый символ не должен быть цифрой.
- Регистр букв имеет значение: переменные `apple` и `APPLE` — это разные переменные.
- Зарезервированные слова языка (например, `let`, `class`, `return`, `function`) нельзя использовать как имя переменной.

Правило хорошего тона — использовать понятные, описательные имена переменных, например: `userName`, `shoppingCart`.

**Константы.** Для объявления переменной, значение которой не должно изменяться, используется ключевое слово `const`:

```js
const myBirthday = '18.04.1982';

myBirthday = '01.01.2001'; // ошибка, нельзя переприсвоить константу
```

Константы, значение которых известно ещё до выполнения программы, принято записывать заглавными буквами и через знак подчёркивания:

```js
const COLOR_RED = "#F00";
const COLOR_GREEN = "#0F0";
```

## Типы данных

Переменная в JavaScript может содержать любые данные — JavaScript является **динамически типизированным** языком: типы данных существуют, но переменные не привязаны ни к одному из них.

```js
let message = "привет";
message = 123456; // тип значения изменился, ошибки нет
```

Всего в языке восемь основных типов данных.

**1. Number (число)**

Представляет как целые, так и числа с плавающей точкой:

```js
let n = 123;
n = 12.345;
```

Помимо обычных чисел, к этому типу относятся так называемые «специальные числовые значения»: `Infinity`, `-Infinity` и `NaN` (Not a Number — результат ошибки вычисления):

```js
alert(1 / 0); // Infinity
alert("не число" / 2); // NaN, деление некорректно
```

**2. BigInt (большое целое число)**

Тип `Number` не может содержать числа больше `2^53` (или меньше `-2^53`). Для работы с очень большими целыми числами используется `BigInt` — число дополняется символом `n` в конце:

```js
const bigInt = 1234567890123456789012345678901234567890n;
```

**3. String (строка)**

Строка в JavaScript должна быть заключена в кавычки:

```js
let str = "Мои строки";
let str2 = 'Одинарные кавычки тоже подходят';
let phrase = `можно вставить ${str}`; // обратные кавычки (шаблонные строки)
```

Двойные и одинарные кавычки — «простые» кавычки, разницы между ними в JavaScript нет. Обратные кавычки — «расширенная функциональность»: с их помощью можно встраивать переменные и выражения в строку, обернув их в `${…}`.

**4. Boolean (логический тип)**

Может содержать всего два значения: `true` (правда) и `false` (ложь):

```js
let nameFieldChecked = true;
let ageFieldChecked = false;
```

Такой тип часто используется для хранения значений типа «да/нет».

**5. Null**

Специальное значение, которого нет в других языках. Это отдельный тип, содержащий только значение `null`. Это не «ссылка на несуществующий объект» и не «нулевой указатель», а специальное значение, представляющее «ничего», «пусто» или «значение неизвестно».

```js
let age = null;
```

**6. Undefined**

Значение `undefined` также стоит особняком. Оно означает, что «значение не было присвоено».

```js
let age;
alert(age); // выведется "undefined"
```

**7. Object (объект)**

Единственный из всех типов данных, который не является примитивом. Объекты используются для хранения коллекций данных и более сложных сущностей.

```js
let user = {
  name: "Иван",
  age: 30
};
```

**8. Symbol (символ)**

Используется для создания уникальных идентификаторов для объектов.

**Оператор `typeof`.** Позволяет узнать тип переданного значения:

```js
typeof undefined // "undefined"
typeof 0         // "number"
typeof "foo"     // "string"
typeof true      // "boolean"
typeof null      // "object" (это ошибка языка, сохранённая для совместимости)
typeof {}        // "object"
```

### Взаимодействие: alert, prompt, confirm

Для взаимодействия со страницей браузер предоставляет ряд встроенных функций.

**alert**

Показывает окно с сообщением и ожидает, пока пользователь нажмёт «OK»:

```js
alert("Привет");
```

Мини-окно с сообщением называется **модальным**: оно не даёт пользователю взаимодействовать с остальной страницей, пока он не закроет окно.

**prompt**

Выводит окно с текстовым сообщением, полем для ввода и кнопками «OK/Отмена»:

```js
result = prompt(title, [default]);
```

- `title` — текст, который будет показан пользователю;
- `default` — необязательный второй параметр, значение по умолчанию в поле ввода.

```js
let age = prompt('Сколько вам лет?', 100);

alert(`Вам ${age} лет!`);
```

Пользователь может ввести что-то в текстовое поле и нажать «OK» — тогда значение вернётся в переменную `result`, либо отменить ввод, нажав «Отмена» — тогда вернётся `null`.

> В браузере Internet Explorer второй аргумент важно указывать всегда, иначе вместо пустой строки в поле ввода может появиться текст `"undefined"`.

**confirm**

Выводит окно с вопросом `question` и двумя кнопками: «OK» и «Отмена»:

```js
result = confirm(question);
```

Результат — `true`, если нажата кнопка «OK», и `false` — в случае нажатия «Отмена» или клавиши `Esc`:

```js
let isBoss = confirm("Вы здесь главный?");

alert(isBoss); // true, если нажата OK
```

**Общая черта всех трёх функций (alert, prompt, confirm):** окна являются модальными — они приостанавливают выполнение скрипта и не дают взаимодействовать с остальной страницей, пока пользователь не закроет окно. Также место расположения окна и его внешний вид определяются браузером — изменить это средствами JavaScript нельзя.
